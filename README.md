# 📝 To-Do List App (Python GUI)

A simple and **beautiful To-Do List app** built with **Python Tkinter**.
Keep track of your tasks, mark them as done, and delete them easily! ✅❌

---

## 🚀 Feature

* Add tasks quickly 🖊️
* Mark tasks as done ✅
* Delete tasks 🗑️
* Tasks are saved in **`tasks.json`**, so your list persists after closing the app
* Responsive GUI — looks great even when you resize the window
* Color-coded tasks: green for done, red for pending 🌈

---

## 💻 Installation

1. Make sure you have **Python 3** installed
2. Clone the repository:

```bash
git clone https://github.com/x0rma-404/todobeta.git
```

3. Navigate to the project folder:

```bash
cd todobeta
```

4. Run the app:

```bash
python todo.py
```
